В репозитории представлен генератор сетевых пакетов с графическим интерфейсом для ручного создания и отправки произвольных IP/TCP/UDP/ICMP и парсер capture-файлов.

Возможности генератора пакетов:

* Полный контроль -  Редактирование всех полей IP, TCP, UDP, ICMP заголовков
* Автоопределение - Сетевые интерфейсы, IP, MAC — всё подхватывается автоматически
* Умный MAC - Алгоритм сам определяет MAC назначения (ARP, шлюз, broadcast) 
* Авторасчет - Контрольные суммы, длины, TTL подставляются по умолчанию
* Тестовые искажения - Можно задать неверную длину, смещение, чексумму
* Очередь пакетов - Отправка последовательности с настройкой интервалов и повторов
* Анализ дампов - Парсер capture-файлов в формате K12

Интерфейс генератора пакетов:

- Выбор сетевого интерфейса (IP и MAC подтягиваются)
- Заполнение IP заголовка (ID, TTL, длина, смещение, чексумма)
- Вкладки для TCP / UDP / ICMP
- Кнопки: «Отправить», «Автоопределение MAC», «ARP», «Очередь»

Для запуска генератора пакетов необходмо выполнить ```sudo python ui.py```

Для работы с парсером можно использовать следующие команды:
```bash
# Базовый запуск
python k12_parser.py capture.txt

# Сохранить результат в файл
python k12_parser.py capture.txt -o output.txt

# Показать только первые N пакетов
python k12_parser.py capture.txt -n 5

# Подробный режим (с информацией о файле)
python k12_parser.py capture.txt -v

# Справка по всем параметрам
python k12_parser.py --help
```
